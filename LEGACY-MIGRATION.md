22 октября 2026 года настроен и проверен отдельный SSH-ключ Mac для старого сервера `198.51.100.20` (Ubuntu 24.04, hostname `srv1089523`). Вход: `ssh vpn-old` или `ssh root@198.51.100.20`. Приватный ключ хранится только на Mac: `/Users/vladislav/.ssh/id_ed25519_195_35_56_165`, права 600. Проверка выполнена с отключённой парольной и интерактивной аутентификацией.

Публичный ключ добавлен к существующим `authorized_keys`, прежние ключи сохранены. Резервная копия находится на старом сервере в `/root/.ssh/authorized_keys.before-kingline-20261022`. Прежний SSH-конфиг Mac сохранён в `private/ssh-config-before-legacy-key-*`. Пароль в файлы проекта не записан.

Обнаружены компоненты запрошенного переноса:

| Компонент | Расположение | Служба / домен |
|---|---|---|
| VPN-бот | `/root/kingline/main.py` | `kingline_bot.service` |
| API сайта | `/root/kingline_site/backend/server.py` | `kingline-site-api.service` |
| Файлы сайта | `/var/www/kingline_site` | `kingline.online`, `www.kingline.online` |
| Оплата | Прокси Nginx на `127.0.0.1:8088` | `pay.kingline.online` |
| Старая панель и подписки | 3x-ui и локальные прокси | `vpn.kingline.online`, `sub.kingline.online`, `sub-ru.kingline.online` |

На старом сервере также работают PostgreSQL 16, Stream/MediaMTX/coturn, Lexicon и почтовые службы. Их наличие нужно учитывать при окончательном выводе сервера из эксплуатации. Источник пока продолжает обслуживать пользователей; сайт, бот, базы и DNS на новый адрес ещё не переключались.

На управляющем сервере в Литве `198.51.100.10` свободно около 91 ГБ диска и 6,3 ГБ доступной RAM, 2 vCPU на момент проверки. На нём уже работают Remnawave, PostgreSQL, Caddy, подписки и DNS. Перед переносом нужны карта баз/секретов/платежей и связей старого бота с 3x-ui, согласованный снимок данных, тестовая копия на целевом сервере, затем переключение единственного экземпляра бота и доменов. Два рабочих экземпляра бота одновременно запускать не следует.

Срок старого сервера, по сообщению владельца 22 октября: осталось пять дней. Доступ по ключу подготовлен; перенос приложений — следующий этап.
